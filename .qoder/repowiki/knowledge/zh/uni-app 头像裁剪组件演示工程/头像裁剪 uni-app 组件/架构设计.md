模块为标准的 uni_modules 插件结构：`package.json` 声明入口 `components/img-cropper/img-cropper.vue`，并通过 `uni_modules.platforms` 限定 App（app-vue）与 H5 平台；`pages/demo/demo.vue` 是配套的示例页面。

核心组件 `img-cropper.vue` 采用 Vue 3 Composition API + TypeScript 的 `defineComponent` 写法，内部按职责划分为：
- 状态层：visible/imageSrc/translateX/translateY/scale/rotation 等 ref 管理弹窗与图片变换；
- 布局计算层：framePx/cropAreaWidth/centerOffsetX/Y/displayedH 等 computed 统一用 `Math.floor` 取整以规避 APP 端浮点像素偏移；
- 交互层：touchStart/touchMove/touchEnd 处理单指拖拽与双指缩放（距离比驱动 scale，范围 1~3），并维护 isMultiTouch 避免手势冲突；
- 渲染层：全屏遮罩 + 底部弹出面板，使用 4 块半透明 mask 围出裁剪框，配合绝对定位 image 实现平移/缩放/旋转；
- 裁剪层：`cropImage` 实现「帧-图交叉区域」算法，先求屏幕坐标系下 frame ∩ image 矩形，再映射回原图坐标经 Canvas drawImage 绘制，并按 rot=0/90/180/270 分别做 translate+rotate 变换，最后 `exportCanvas` 调用 `uni.canvasToTempFilePath` 导出临时文件。

对外暴露 `open(src)` / `close()` 两个命令式方法（通过 `expose`），并通过 `complete`/`cancel`/`error` 三个事件回调结果；所有尺寸在 APP 端禁用 transform:scale、CSS inset、margin:auto 居中，改用显式 left/top/width/height 计算以保证兼容性。
